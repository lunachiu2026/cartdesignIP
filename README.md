# 暮光集所 Muguang Market

以 Vue 3、Vite、Pinia 與 Bootstrap 5 製作的文創選物平台前端展示版。系統包含顧客會員與購物流程、創作者工作室，以及平台管理員審核與營運後台。

## 技術架構

- Vue 3 Composition API
- Vite
- Vue Router
- Pinia
- Bootstrap 5 與 Bootstrap Icons
- 瀏覽器 `localStorage` 展示資料
- Google Fonts 與 Unsplash 展示圖片

## 執行方式

```bash
npm install
npm run dev
```

正式建置與預覽：

```bash
npm run build
npm run preview
```

## 展示帳號

| 身分 | 帳號 | 密碼 | 登入入口 |
|---|---|---|---|
| 顧客會員 | `member@demo.tw` | `123456` | `/account/login` |
| 創作者 | `creator@demo.tw` | `123456` | `/creator/login` |
| 平台管理員 | `admin@muguang.tw` | `admin123` | `/muguang/admin` |

顧客登入頁會顯示展示帳號；創作者及管理員登入頁需點擊「展示模式」才會帶入測試帳號。平台管理員入口不會出現在公開網站導覽中。

平台管理後台的「重設示範資料」可還原會員、創作者、商品、一般訂單、月租訂單、模擬通知及購物車。資料結構更新時會使用新的儲存版本，避免舊版展示資料造成欄位錯誤。

## 前台功能

- 文青淺色系首頁、精選商品及創作者介紹
- 商品搜尋、分類、價格篩選及排序
- 商品詳情、創作者品牌頁與相關商品
- 購物車數量調整、移除商品及運費計算
- 登入後結帳、收件資料及付款方式
- 依創作者拆分訂單並扣除展示庫存
- 未通過審核、停權或主動下架商品不會顯示於前台
- 月租逾期鎖定的商品仍保留作品資訊，但標示「暫停販售」且不能加入購物車

## 顧客會員

| 路由 | 功能 |
|---|---|
| `/account/login` | 顧客登入 |
| `/account/register` | 顧客註冊 |
| `/account/orders` | 歷史訂單與狀態篩選 |
| `/account/orders/:id` | 商品、付款、收件資訊及配送進度 |
| `/account/profile` | 姓名、電話與預設地址 |

- 前台人物入口只屬於顧客，不會連到任何後台
- 未登入前往結帳時，會先導向登入並保留原本目的地
- 訂單透過 `customerId` 綁定會員
- 顧客只能讀取自己帳號所屬的訂單
- 顧客與後台登入可同時存在，彼此不互相覆蓋

## 創作者工作室

- 完整合作申請：品牌介紹、創作理念、材料、所在地、作品集及申請原因
- 註冊頁清楚說明 NT$299／月方案、審核、退款、續費及 3 天寬限規則
- 註冊完成後必須閱讀確認視窗並完成首期模擬付款
- 付款前與審核中只能查看合作進度、付款紀錄及維護品牌資料
- 審核通過前不能進入工作室總覽、商品或訂單管理
- 工作室總覽、商品新增與編輯、圖片預覽上傳及上下架
- 只能管理自己品牌的商品與訂單
- 訂單狀態可更新為準備中、已出貨及已完成
- 申請被退回時首期款自動建立模擬退款，更新資料後需重新付款送審
- 核准後產生含一次性 token 的模擬 Email，連結會帶回創作者登入頁

### 月租路由

| 路由 | 功能 |
|---|---|
| `/creator/onboarding` | 註冊、付款、審核及啟用進度 |
| `/creator/subscription/checkout` | NT$299 月租模擬付款 |
| `/creator/subscription/success` | 付款成功與開始審核說明 |
| `/creator/subscription` | 月租狀態、效期、付款退款紀錄與展示工具 |
| `/creator/mail` | 模擬審核通知信與登入連結 |

### 月租狀態

| 狀態 | 行為 |
|---|---|
| `unpaid` | 尚未支付首期月租，不能送審 |
| `prepaid` | 首期已付款，等待審核，尚未開始計費 |
| `active` | 月租有效，可正常上架與販售 |
| `grace` | 到期後 3 天寬限期，仍可販售並提示補繳 |
| `locked` | 第 4 天起鎖定新增與上架，前台商品暫停販售 |
| `refunded` | 審核未通過，首期款已建立模擬退款 |

月租從平台核准當日開始計算一個月，而不是付款日。逾期鎖定不會修改商品原本的上下架狀態，因此補繳後，鎖定前原本上架中的商品會自動恢復；原本下架的商品仍維持下架。已成立訂單在鎖定期間仍可繼續處理與出貨。

## 平台管理後台

- 營運數據、創作者、商品、分類與全站訂單管理
- 公開網站不顯示管理員登入入口
- 創作者列表不能直接核准，必須先進入申請詳情
- 審核詳情包含品牌故事、製作方式、材料、聯絡資料、作品集及商品預覽
- 審核詳情同時顯示月租訂單、付款狀態、起算日、到期日及退款紀錄
- 首期月租未付款時不能核准
- 核准會啟動首期月租並建立模擬 Email 登入通知
- 退回會保存原因並自動建立首期款模擬退款
- 可附理由停權及恢復資格
- 保存審核日期、結果、原因及操作人員紀錄

## 權限設計

展示版將登入狀態拆成兩組：

- `customerSession`：只負責顧客會員、結帳與顧客訂單
- `backofficeSession`：只負責 `creator` 或 `admin` 後台角色

Vue Router 會阻擋未登入的受保護頁面，Pinia 操作也會再次檢查角色、商品所有權、訂單所有權、創作者審核與月租狀態。路由守衛負責畫面導向，資料層檢查則避免透過前端直接呼叫不屬於該角色的操作。

創作者權限分成三層：未核准只能查看申請與付款；已核准且月租有效或在寬限期可完整操作；月租鎖定後仍可處理既有訂單與編輯資料，但不能新增或重新上架商品。

## 月租展示測試

使用創作者展示帳號登入後，前往 `/creator/subscription`，可切換：

- `Active`：月租正常有效
- `Grace`：到期後 3 天付款寬限期
- `Locked`：逾期第 4 天，前台商品暫停販售
- 重設展示情境：回到依日期計算的真實展示狀態

切換為 `Locked` 後可回到前台確認商品仍然可見，但購買、購物車及結帳均被阻擋。點擊續訂並完成 NT$299 模擬付款後，原本上架中的商品會自動恢復販售。

## 安全限制

本專案仍是純前端展示版，不包含伺服器、資料庫、真實金流、真實 Email、後端排程或正式身分驗證。付款、退款、通知信、token 與月租時間切換皆為 `localStorage` 模擬；前端密碼及路由守衛都可以由瀏覽器使用者修改，因此不能直接作為正式環境的安全機制。

正式上線至少需要：

- 後端 API 驗證每次請求的角色與資料所有權
- Argon2id 或 bcrypt 密碼雜湊
- Secure、HttpOnly、SameSite Cookie session
- CSRF 防護、登入限流與異常鎖定
- Email 驗證、密碼重設及管理員雙因素驗證
- 管理操作稽核紀錄
- 資料庫交易、庫存鎖定與正式金流回呼驗證
- 由後端排程每日更新月租、寬限及鎖定狀態
- 金流定期定額、退款 API 與 Email 寄送服務

目前版本適合 UI 展示、操作流程確認及後續串接正式 API 前的原型驗證。
